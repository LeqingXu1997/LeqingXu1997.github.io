# Leqing Xu - Personal Website

个人网站项目 | Personal Website Project

## 项目简介 | Project Overview

这是徐乐青的个人学术网站，展示其在可持续能源技术领域的研究工作、个人兴趣爱好以及学术思考。

This is Leqing Xu's personal academic website, showcasing research work in sustainable energy technology, personal interests, and academic reflections.

## 特性 | Features

- ✅ 完全响应式设计，适配所有设备
- ✅ 中英双语支持，一键切换
- ✅ 现代化的用户界面和流畅动画
- ✅ 六个主要板块：
  - 首页（Hero Section）
  - 关于我（教育背景、研究兴趣）
  - 研究与论文
  - 爱好与兴趣（篮球、滑雪、旅游）
  - 推荐书目
  - 博客与感想

- ✅ Fully responsive design for all devices
- ✅ Bilingual support (Chinese/English) with one-click toggle
- ✅ Modern UI with smooth animations
- ✅ Six main sections:
  - Hero/Home
  - About (Education, Research Interests)
  - Research & Publications
  - Hobbies (Basketball, Skiing, Travel)
  - Reading List
  - Blog & Reflections

## 如何使用 | How to Use

### 本地运行 | Run Locally

1. 克隆或下载此项目
   Clone or download this project

2. 直接在浏览器中打开 `index.html` 文件
   Open `index.html` directly in your browser

或使用本地服务器（推荐）：
Or use a local server (recommended):

```bash
# 使用 Python
python -m http.server 8000

# 使用 Node.js (http-server)
npx http-server

# 使用 PHP
php -S localhost:8000
```

然后在浏览器访问 `http://localhost:8000`
Then visit `http://localhost:8000` in your browser

### 自定义内容 | Customize Content

1. **个人信息** | Personal Information
   - 编辑 `index.html` 中的文本内容
   - Edit text content in `index.html`

2. **研究论文** | Research Publications
   - 在 `#research` 部分添加你的论文信息
   - Add your publications in the `#research` section

3. **博客文章** | Blog Posts
   - 在 `#blog` 部分添加你的文章
   - Add your articles in the `#blog` section

4. **社交媒体链接** | Social Media Links
   - 更新页脚的社交媒体链接
   - Update social media links in the footer

5. **颜色主题** | Color Theme
   - 修改 `css/style.css` 中的 CSS 变量
   - Modify CSS variables in `css/style.css`

```css
:root {
    --primary-color: #2563eb;    /* 主色调 */
    --secondary-color: #10b981;  /* 次要色调 */
    --accent-color: #f59e0b;     /* 强调色 */
}
```

## 部署 | Deployment

### GitHub Pages

1. 创建 GitHub 仓库 | Create a GitHub repository
2. 上传所有文件 | Upload all files
3. 在仓库设置中启用 GitHub Pages | Enable GitHub Pages in repository settings
4. 选择 main 分支 | Select main branch
5. 访问 `https://yourusername.github.io/repository-name`

### Netlify

1. 注册 Netlify 账号 | Sign up for Netlify
2. 连接 GitHub 仓库或直接拖拽文件夹 | Connect GitHub repo or drag & drop folder
3. 自动部署 | Automatic deployment

### Vercel

1. 注册 Vercel 账号 | Sign up for Vercel
2. 导入 GitHub 仓库 | Import GitHub repository
3. 一键部署 | One-click deployment
