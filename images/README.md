# 个人照片占位说明

请将你的个人照片命名为 `profile.jpg` 并放置在 `images/` 文件夹中。

## 推荐规格：
- 格式：JPG 或 PNG
- 尺寸：至少 **360×480 像素**（竖版长方形，3:4 比例）
- 文件大小：建议小于 500KB
- 照片应为专业形象照（半身照或证件照风格）

## 显示尺寸：
- 桌面端：180×240 像素
- 平板端：135×180 像素
- 手机端：108×144 像素

## 使用说明：
1. 准备一张正方形的个人照片
2. 将照片重命名为 `profile.jpg`
3. 放置在 `images/` 文件夹中
4. 刷新网页即可看到照片

如果没有照片，网站会显示一个头像图标占位符。

# 微信二维码说明

请将你的微信二维码图片命名为 `wechat-qr.jpg` 并放置在 `images/` 文件夹中。

## 推荐规格：
- 格式：JPG 或 PNG
- 尺寸：至少 400x400 像素（正方形）
- 文件大小：建议小于 200KB
- 二维码应清晰可扫

## 使用说明：
1. 在微信中生成你的个人二维码
2. 截图或保存二维码
3. 将图片重命名为 `wechat-qr.jpg`
4. 放置在 `images/` 文件夹中
5. 点击网站footer的微信图标即可弹出二维码

如果没有二维码图片，弹窗会显示占位符。

同时记得在 `index.html` 中更新你的微信号文本。
